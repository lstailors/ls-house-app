                           WORKFLOWS INDEX
================================================================================

1. MORNING BRIEF
   Schedule: 6:00 AM, Monday-Saturday (America/New_York)
   Nodes: 5
   Purpose: Daily summary of open todos and upcoming meetings
   
   Nodes:
   - Schedule Trigger (6am weekdays)
   - HTTP GET: Fetch open todos from ERPNext
   - HTTP GET: Fetch Cal.com meetings (today's bookings)
   - Code Node: Format with priority emoji (🔴 High, 🟡 Medium, 🟢 Low)
   - HTTP POST: Send formatted message to BlueBubbles
   
   Data Flow: Schedule → Todos & Meetings (parallel) → Format → Send

---

2. MIDDAY CHECK
   Schedule: 12:00 PM, Monday-Saturday (America/New_York)
   Nodes: 5
   Purpose: Alert for overdue and due-today todos
   
   Nodes:
   - Schedule Trigger (12pm weekdays)
   - HTTP GET: Fetch todos with date <= TODAY
   - If Node: Check if any todos exist
   - Code Node: Format alert message (only if todos found)
   - HTTP POST: Send alert to BlueBubbles (conditional)
   
   Data Flow: Schedule → Fetch → Check → Format (if any) → Send

---

3. EOD DIGEST
   Schedule: 6:00 PM, Monday-Saturday (America/New_York)
   Nodes: 6
   Purpose: End-of-day summary with completion counts
   
   Nodes:
   - Schedule Trigger (6pm weekdays)
   - HTTP GET: Fetch closed todos (modified today) [PARALLEL]
   - HTTP GET: Fetch remaining open todos [PARALLEL]
   - Merge Node: Combine both responses
   - Code Node: Format summary with counts (✅ Completed: X, 📋 Remaining: Y)
   - HTTP POST: Send digest to BlueBubbles
   
   Data Flow: Schedule → [Closed & Open parallel] → Merge → Format → Send

---

4. TODO OVERDUE ALERT
   Trigger: Webhook POST /todo-overdue
   Nodes: 4
   Purpose: Send immediate alert when todo marked overdue
   
   Nodes:
   - Webhook Trigger: POST /todo-overdue
   - If Node: Check if status === "Open"
   - HTTP POST: Send alert to BlueBubbles (only if Open)
   - Respond to Webhook: Return { status: "alerted" }
   
   Data Flow: Webhook → Check Status → Alert (if Open) → Response
   
   Webhook Payload:
   {
     "name": "Todo Name",
     "status": "Open"
   }

---

5. SOFIA TODO CREATOR
   Trigger: Webhook POST /sofia-todo
   Nodes: 3
   Purpose: Create todos from Sofia voice assistant
   
   Nodes:
   - Webhook Trigger: POST /sofia-todo
   - HTTP POST: Create todo in ERPNext
   - Respond to Webhook: Return { status: "created" }
   
   Data Flow: Webhook → Create → Response
   
   Webhook Payload:
   {
     "title": "Task Title",
     "description": "Task Description",
     "priority": "High|Medium|Low"
   }

---

6. SIMONE SIGNAL TODO CREATOR
   Trigger: Webhook POST /simone-signal
   Nodes: 5
   Purpose: Create todos from Simone Signal with high-urgency alerts
   
   Nodes:
   - Webhook Trigger: POST /simone-signal
   - HTTP POST: Create todo in ERPNext
   - If Node: Check if urgency === "high"
   - HTTP POST: Send alert to BlueBubbles (only if high urgency)
   - Respond to Webhook: Return { status: "created" }
   
   Data Flow: Webhook → Create → Check Urgency → Alert (if high) → Response
   
   Webhook Payload:
   {
     "title": "Task Title",
     "description": "Task Description",
     "urgency": "high|medium|low"
   }
